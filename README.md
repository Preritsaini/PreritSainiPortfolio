# Prerit Saini — Flutter Software Engineer Portfolio

High-velocity portfolio for **Prerit Saini**, Flutter Software Engineer shipping production cross-platform mobile apps across iOS and Android with Clean Architecture, Riverpod, Provider, BLoC, and Flame engine.

## 📱 Core Highlights
- **Live Interactive Mobile Simulator**: 4 live apps (ReadHub E-Book Reader with BLoC, Govindpura Hyperlocal Commerce with offline sync, CyberRunner 2D Game with Flame engine, Architecture Token Showcase).
- **Clean Architecture Deep Dive**: Structural breakdown of Domain, Data, and Presentation layers with deterministic 60–120 FPS high refresh-rate budgeting.
- **Lead Capture & Direct Dispatch**: Integrated with Firebase Cloud Firestore (`portfolio-8a020`) and 1-click Gmail Web compose.
- **Adaptive Dark / Light Themes**: Custom glassmorphism, micro-animations, and high-contrast typography.
- **Curriculum Vitae / ATS Modal**: Interactive preview and direct download of authentic resume PDF.

## 🛠 Tech Stack
- **Web App**: Next.js 16 (App Router, Turbopack, React 19)
- **Styling**: Modern CSS Design System, Glassmorphism, CSS Variables
- **Backend / Database**: Cloud Firestore (Firebase)
- **Audio Synth**: Web Audio API Synthesizer

## 🚀 Getting Started

Run the development server locally:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

## 📦 Production Build

```bash
npm run build
npm run start
```
